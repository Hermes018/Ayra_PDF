# PROTOTYPE SCOPE — LocalPDF Studio v0.2.0-prototype (Linux)

- **Deadline:** Sat 2026-11-07 23:59 Asia/Dhaka. Release candidate `v0.2.0-rc1` at Sat 18:00.
- **Platform:** Linux x86_64 (Ubuntu 24.04 base / Zorin 18.1 dev machine; Fedora RPM). Android is paused; Windows is not in scope for this release.
- **Feature freeze:** no new user-facing features. Allowed: the ADR-018 engine restructure, bug fixes, hiding features, packaging, tests.
- **Labs:** LaTeX insert (checklist 2.16) and ink-to-text (8.10) are behind a "Labs" setting, **off by default**. They are not part of any flow below.

## How flows are tested
- **Automation:** each flow is an automated end-to-end test against the **real app**: the debug or release binary, driven by `tauri-driver` + `WebKitWebDriver` over W3C WebDriver.
- **Code:** test code lives in `master/e2e/` (Python 3 standard library only; dev tooling, never shipped).
- **One-command run:** `python3 master/e2e/run.py [--flows 1,2,…] [--binary <path>]`. It writes `master/e2e/out/report.json`, plus screenshots for each failure.
- **Ground truth outside the app:** checks use independent tools (`pdftotext`, `pdfinfo`, `qpdf --check`, pdf.js in the webview where noted) and never trust the app's own claims.
- **Builds:** every heavy build goes through `master/tools/build-lock.sh`.

## The 12 flows: pass criteria (all must hold)

| # | Flow | PASS when |
|---|---|---|
| 1 | **Install and cold launch** | (a) The package installs: `.rpm` on Fedora, plus AppImage; `.deb` if cheap. (b) A cold launch shows the main window in **< 3 s** (process start → `document.readyState == complete` and Studio root visible). (c) **Zero** console errors (WebDriver browser log level SEVERE, or app stderr panic/ERROR lines). |
| 2 | **Open PDFs** | (a) small, 200+ page, scanned and encrypted files open; encrypted prompts for a password and opens with `lpdf-test`. (b) The page count matches `pdfinfo`. (c) Malformed / hostile files show a user-visible error (or degraded-mode notice) and the app stays alive and responsive. No crash. |
| 3 | **Navigate** | Pan, zoom (buttons, presets, ctrl+wheel), pinch (2 synthetic touch pointers) and Fit Width / Fit Page change the view as expected (measured transform). Thumbnails render for the open file. Two documents open as separate tabs (or split panes) and switching keeps each one's view state. |
| 4 | **Ink** | Pen and highlighter strokes are created (vector layer node count +1 each). The whole-stroke eraser removes a stroke. The partial eraser splits or trims a stroke (the remaining geometry is checked). Undo and redo restore the exact previous state. |
| 5 | **Shapes and hatching** | Rectangle, ellipse, polygon and revision cloud are created. A hatched **concave polygon**, saved and re-extracted (pdftotext bbox / PDF content inspection), has **every hatch segment inside the polygon** (ERR-007). Every hatch pattern produces **distinct** output. |
| 6 | **Measure** | Two-point calibration sets the scale. Length, area and angle measurements match the expected values within 0.5 %. They appear in the Ledger. CSV export writes a file whose rows match. |
| 7 | **Insert** | Text box, callout, sticky note, stamp and signature (draw mode) are each created, visible, and survive save → reopen (flow 11). |
| 8 | **Redact** | Mark a text region and commit the redaction. In the **new** output file, `pdftotext` no longer contains the redacted string, and `qpdf --check` passes. The original file is unchanged (hash). |
| 9 | **Edit PDF text in place** | Enter Edit Text mode and change a text block. After saving, `pdftotext` of the new file contains the new text and not the old text. The original is unchanged. |
| 10 | **Organize** | Reorder, rotate, delete and merge (two files). The output page count and order match (`pdfinfo` + per-page text). Rotation shows in `pdfinfo -l`. The original is unchanged. |
| 11 | **Save and reopen** | Save creates a **new** file (the original's hash is unchanged). Reopening in our app shows the markups. The file passes `qpdf --check`. Poppler (`pdftotext` / `pdfinfo`) reads it, and pdf.js (our viewer) renders the annotations. |
| 12 | **Soak** | A 1-hour scripted loop (open → annotate → save → close, plus navigation) causes no crash. RSS stays within 1.5× its value after the first 5 minutes. No growing temp or file-descriptor leak. |

## Triage
- **P0:** breaks a main flow above, or loses or corrupts data. Must be fixed before rc1.
- **P1:** visible problem with a workaround. Fixed if time allows; otherwise listed in `KNOWN_ISSUES.md`.
- **P2:** after the release.
- **Where bugs go:** `master/logs/BUGS.md` (automated and agent-found) and `master/logs/DOGFOOD.md` (owner testing).
