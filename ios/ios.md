# ios/ — iOS build

**Status:** not started, and **not part of the protocol's phase plan** (phases 13 and 14 cover macOS and Android only). The scope rule (DON'T-13) requires a PLAN_LOG entry, an ADR and your approval before iOS work starts.

When it starts, Tauri mobile project files (`tauri ios init` output), the iOS overlay config and iOS-only docs go here.
